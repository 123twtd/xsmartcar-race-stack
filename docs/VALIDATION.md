- 检测解码 3 项单元测试通过；

## 硬件环境说明

三个入口来自实际完赛版本；这里列出的“尚未完成”仅表示赛后开源整理没有在当前电脑上重新执行整套板端与实车测试。更换硬件、系统、模型或标定后，应根据实际设备重新确认，具体的上位机、下位机和协议方法分别见对应 README 与 [`PROTOCOL.md`](PROTOCOL.md)。
